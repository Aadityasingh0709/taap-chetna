# Contributing to Taap Chetna

Thank you for your interest in contributing to **Taap Chetna**! Every contribution—from bug reports to new feature developments—is greatly appreciated.

---

## 🚀 How to Contribute

### 1. Reporting Bugs
- Check the [Issues](https://github.com/Aadityasingh0709/taap-chetna/issues) tab to verify if the issue has already been reported.
- If not, create a new issue using our **Bug Report** template.
- Include detailed reproduction steps, expected behavior, and environment specs.

### 2. Suggesting Features
- Open an issue using the **Feature Request** template.
- Explain the motivation and the exact problem it solves for heat-health monitoring.

### 3. Pull Request Guidelines
1. **Fork** the repository and create your feature branch:
   ```bash
   git checkout -b feature/my-new-feature
   ```
2. Ensure you have installed all dependencies:
   ```bash
   npm run install-all
   ```
3. Test changes locally:
   ```bash
   npm run dev
   ```
4. Commit your changes with concise and descriptive commit messages.
5. Push to your branch and submit a Pull Request against the `main` branch.

---

## 📌 Code Style & Standards
- Use modern JavaScript (ES6+) syntax.
- Maintain clean, modular React components.
- Do not commit secrets, API keys, or private `.env` configurations.
