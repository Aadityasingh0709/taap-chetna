# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Taap Chetna, please do not report it publicly via GitHub issues.

Instead, please report it privately:
- Contact the project maintainer via GitHub: [@Aadityasingh0709](https://github.com/Aadityasingh0709)
- Include detailed steps to reproduce the vulnerability, proof-of-concept payloads, and potential impact.

We take security issues seriously and will review and respond promptly.
